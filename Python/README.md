# Python

Python knowledge, concepts, practices, and reusable technical references developed as part of the engineering learning journey.

This section focuses on understanding Python as an **engineering tool**, particularly in preparation for Data Engineering and eventually AI Engineering.

---

## Purpose

The goal is not to document every Python feature or reproduce an entire course.

This section captures Python knowledge that is:

- Fundamental
- Reusable
- Important for engineering work
- Relevant to Data Engineering
- Useful across multiple projects
- Worth retaining as long-term technical knowledge

---

## Learning Approach

Python is being learned through a combination of:

- Structured learning material
- Targeted exercises
- Practical experimentation
- Real projects
- Documentation
- Testing
- Git and GitHub workflows

Learning exercises are kept deliberately focused.

If an exercise does not contribute to understanding an important Python concept or applying Python to a real project, it does not need to become permanent repository content.

## Documentation Standard

Python documentation should generally explain:

**What?**
What is the concept?

**Why?**
Why does it matter?

**How?**
How does it work?

**When?**
When should it be used?

**Pitfalls?**
What mistakes should be avoided?

**Application?**
Where is it used in an actual project?

Short examples are encouraged when they clarify a concept.

Large project implementations belong in project repositories rather than here.
